# Linea temporal

Este directorio contiene la **linea temporal macro** de los cinco libros. Cada entrada debe ser un acontecimiento enunciado en una sola frase o una fila breve; no contiene escenas, mecanismos, motivaciones desarrolladas ni prosa.

## Regla de autoridad

- La linea temporal responde **cuándo ocurre qué** y qué continuidad conecta un libro con el siguiente.
- El `00_Book_Map.md` de cada libro responde **cómo funciona narrativamente**: partes, capítulos, escenas, POV, ritmo y consecuencias desarrolladas.
- Los hitos y decisiones del autor conservan prioridad sobre cualquier inferencia de estos archivos.
- `CANON` = fijado por el autor o por un documento de canon vigente.
- `DISEÑO` = organización propuesta para la continuidad.
- `PENDIENTE` = no se completa por conveniencia.
