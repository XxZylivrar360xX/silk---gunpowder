# Escenas guia

Momentos que el autor imagina con suficiente claridad para preservar su verdad emocional antes de decidir la prosa final.

Cada nota debe separar con nitidez:

1. **CANON DEL AUTOR:** lo que debe ocurrir, una imagen, un gesto o una línea entregados por el autor.
2. **Función:** por qué existe el momento.
3. **Libertad de prosa:** todo lo que aún no está decidido y no debe imponerse al capítulo futuro.

No son capítulos ni borradores de prosa. Son la referencia de intención para quien redacte cuando llegue el momento.
