# Ideas sin clasificar

Semillas, fragmentos, líneas sueltas, escenas que todavía no saben a qué capítulo pertenecen. Nada aquí es canon.

Cuando una idea encuentra su lugar, se mueve a la carpeta que le corresponde y se enlaza desde `INDEX.md`. Lo que lleva mucho tiempo aquí sin moverse probablemente pertenece a otra novela.
