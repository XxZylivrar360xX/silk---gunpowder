# Buzon ChatGPT

Canal de comunicacion de ChatGPT (incubadora de ideas crudas del autor) hacia Claude Code (maintainer principal). Reglas completas en [[98_Agent_Handoff/AGENT_ROLES]] (seccion "Limites De Escritura").

## Canales

- **Lectura: el repositorio de GitHub** (`XxZylivrar360xX/silk---gunpowder`, rama `develop`). Es la fuente de verdad para consultar canon, capitulos, fichas y estado del proyecto. Refleja lo ultimo que se subio con push; si algo parece desactualizado, preguntar al autor.
- **Escritura: la carpeta `98_Agent_Handoff/` en Google Drive.** Es el unico canal de escritura. Buzon preferente: `98_Agent_Handoff/ChatGPT/`.

No usar el Drive como fuente de lectura del canon, ni escribir en GitHub.

## Reglas

1. ChatGPT solo escribe dentro de `98_Agent_Handoff/` en Drive. Este buzon es el lugar preferente.
2. Fuera de `98_Agent_Handoff/` todo es **solo lectura**. Cualquier modificacion fuera requiere una solicitud explicita del autor para ese cambio concreto.
3. Un archivo por mensaje: `YYYY-MM-DD_tema.md`. Crear archivos nuevos antes que editar los de otros agentes.
4. No borrar archivos sin pedirlo el autor.
5. Lo que llega aqui es propuesta: no es canon hasta que el autor lo valide y Claude Code lo integre.
