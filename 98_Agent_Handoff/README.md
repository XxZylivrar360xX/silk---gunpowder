# Agent Handoff

Notas compactas para relevo entre agentes.

## Uso

1. Leer `CURRENT_BRIEF.md` al iniciar.
2. Revisar `PENDING.md` antes de editar.
3. Al cerrar una sesion, actualizar `CURRENT_BRIEF.md`.
4. Si hubo decisiones nuevas, agregarlas en `DECISIONS.md`.
5. Si la sesion fue sustantiva, crear una nota breve en `sessions/`.

## Regla

Esto no reemplaza `CLAUDE.md`, `INDEX.md` ni `log.md`.

- `CLAUDE.md`: reglas completas.
- `INDEX.md`: mapa canonico del vault.
- `log.md`: bitacora larga.
- `98_Agent_Handoff/`: relevo rapido.
