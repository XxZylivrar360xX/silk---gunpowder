# Agent Handoff

Notas compactas para relevo entre agentes.

## Uso

1. Leer `START_HERE.md`.
2. Leer `CURRENT_BRIEF.md`.
3. Revisar `PENDING.md` antes de editar.
4. Al cerrar una sesion, actualizar `CURRENT_BRIEF.md`.
5. Si hubo decisiones nuevas, agregarlas en `DECISIONS.md`.
6. Si la sesion fue sustantiva, crear una nota breve en `sessions/`.

## Regla

Esto no reemplaza `CLAUDE.md`, `INDEX.md` ni `log.md`.

- `CLAUDE.md`: reglas minimas de arranque.
- `INDEX.md`: mapa canonico del vault.
- `log.md`: bitacora larga.
- `98_Agent_Handoff/`: relevo rapido.
