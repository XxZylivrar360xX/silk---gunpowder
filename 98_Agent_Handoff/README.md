# Agent Handoff

Notas compactas para relevo entre agentes.

## Uso

1. Leer `START_HERE.md`.
2. Leer `AGENT_ROLES.md` si la tarea implica coordinacion, relevo o trabajo dirigido a otro agente.
3. Leer `CURRENT_BRIEF.md`.
4. Revisar `PENDING.md` antes de editar.
5. Al cerrar una sesion, actualizar `CURRENT_BRIEF.md`.
6. Si hubo decisiones nuevas, agregarlas en `DECISIONS.md`.
7. Si la sesion fue sustantiva o deja trabajo a otro agente, crear una nota breve en `sessions/`.

## Archivos

- `START_HERE.md`: ruta barata de lectura.
- `AGENT_ROLES.md`: responsabilidades de ChatGPT, Codex y Claude Code.
- `CURRENT_BRIEF.md`: estado vivo del proyecto.
- `PENDING.md`: decisiones abiertas y siguiente trabajo.
- `DECISIONS.md`: decisiones recientes.
- `sessions/`: handoffs compactos y notas dirigidas entre agentes.

## Notas Dirigidas

Las notas entre agentes viven en `sessions/`.

Convencion sugerida:

`AAAA-MM-DD_origen_para_destino_tema.md`

Ejemplos:

- `2026-08-28_chatgpt_para_claude_revision_capitulo_08.md`
- `2026-08-28_chatgpt_para_codex_pistas_abiertas.md`
- `2026-08-28_codex_para_claude_beats_capitulo_09.md`

## Regla

Esto no reemplaza `CLAUDE.md`, `INDEX.md` ni `log.md`.

- `CLAUDE.md`: reglas minimas de arranque.
- `INDEX.md`: mapa canonico del vault.
- `log.md`: bitacora larga.
- `98_Agent_Handoff/`: relevo rapido.

Ninguna nota de agente crea canon por si sola. La autoridad final es el autor.
