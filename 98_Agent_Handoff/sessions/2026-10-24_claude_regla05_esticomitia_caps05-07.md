# 2026-10-24 — Regla 05 (esticomitia de una sola voz) y cirugia de dialogo, Caps. 5-7

**Agente:** Claude Code (principal) + tres subagentes de scouting, uno por capitulo.
**Origen:** el autor percibe en el Cap. 6 una "falta de identidad" en los dialogos corridos: ping-pong robotico. El objetivo es transmitir emocion.

## Regla nueva

- Investigacion web (talleres de guion y narrativa): *esticomitia* es el termino clasico y *dialogo de ping-pong* el nombre del vicio. Las tecnicas: cortar replicas, dejar preguntas colgando, contestar lo que no se pregunto, no rematar cada turno, que cada linea tenga una agenda, variar el largo, hablar de otra cosa (Hemingway, Leonard, McKee, Harris).
- Se creo [[12_Craft_Policies/dialogue_rules/05-esticomitia-de-una-sola-voz]]. Su tesis: la emocion esta en la grieta del patron de cada voz. Complementa [[12_Craft_Policies/staging_rules/04-dialogo-de-guion-sin-anclaje]] (entorno), que remite a la 05.
- **Decision del autor:** entre Chiara y Tommaso manda la ficha de Tommaso (sin duelo de epigramas). Se retiro el pasillo como modelo de "esgrima breve" en staging 04.
