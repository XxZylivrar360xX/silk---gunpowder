# Indice de Momentos Hito

Indice cronologico de beats donde un personaje, relacion o mapa de poder cambia de forma irreversible. No reemplaza [[06_Relationships/Hitos]]; apunta a el y registra el orden de uso para prosa.

## Como usar

Antes de escribir una escena que dependa de "esto ya paso" o "todavia no paso", revisar esta lista.

Si una escena nueva cambia de forma irreversible una relacion, deuda, ritual o jerarquia, agregarla aqui con enlace.
