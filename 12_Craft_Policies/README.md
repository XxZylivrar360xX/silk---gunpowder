# Craft Policies

Reglas de oficio que se acumulan **escribiendo**, no antes de escribir. A diferencia de `00_Biblia/`, que se decide de entrada, esto se llena cuando una sesión de prosa revela un problema recurrente.

## Contenido

- `voice/` — una ficha por personaje que habla. Plantilla en `voice/TEMPLATE.md`.

## Regla de uso

Antes de escribir una escena con diálogo: leer la ficha de voz de cada personaje presente. Si un personaje habla en escena y no tiene ficha, créala primero.

## Cuándo se añade una política

Cuando el autor señala el mismo defecto dos veces. Un defecto señalado una vez es una corrección; señalado dos veces es una regla que faltaba.
